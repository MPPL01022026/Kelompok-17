# UI/UX - Mockup

Perlu dipahami bahwa implementasi antarmuka aplikasi dibangun menggunakan framework **Laravel**:

1. **Mobile View**: Tampilan antarmuka berbasis web responsif (_mobile-friendly_) yang dioptimalkan untuk perangkat seluler.
2. **Desktop / Web View**: Tampilan antarmuka yang dioptimalkan untuk layar monitor desktop/laptop/tablet.

Oleh karena itu, aset dan dokumentasi mockup dipisahkan ke dalam direktori `/mobile` dan `/web`.
